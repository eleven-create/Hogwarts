# /scenes/ui — 界面场景

> 菜单 / 对话框 / 背包 / 状态栏 / 选项面板 等。

## 命名约定
- 场景文件：`ui_<功能>.tscn`
- 对应脚本：`scripts/ui/<功能>.gd`

## MVP 目标界面

| 场景 | 功能 |
|---|---|
| `ui_main_menu.tscn` | 主菜单（开始/继续/设置/退出） |
| `ui_dialogue_box.tscn` | 对话框（显示立绘+文字+选项） |
| `ui_stats_panel.tscn` | 属性面板（6属性+状态值） |
| `ui_time_indicator.tscn` | 时间/日期指示器 |

**当前为空**，等待 UI 设计完成后填充。
