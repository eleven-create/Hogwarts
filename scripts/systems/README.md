# /scripts/systems — 游戏系统实现

> 与 `/scenes/systems` 配套的具体系统实现脚本。

## 命名约定
- 类名：`PascalCase`
- 文件名：与类名相同，`.gd` 后缀
- 例如 `InventorySystem.gd` 配 `scenes/systems/sys_inventory.tscn`
